# AGENTS.md

**Humans:** start with [GETTING_STARTED.md](./GETTING_STARTED.md). The factory
skeleton is already seeded. Iterate on the product in `agent/SPEC.md` §1.4
before asking an agent to change application code.

**Agents:** instructions live in [agent/AGENTS.md](./agent/AGENTS.md). Start
every session there.

Key docs in `agent/`:

- `agent/SPEC.md` — architecture contract (source of truth)
- `agent/PLAN.md` — ordered implementation plan
- `agent/INVARIANTS.md` — living falsifiable claims
- `agent/TEST.md` — test and QA plan
- `agent/environment.yaml` — operational environment
- `agent/implementation/` — per-step notes
- `agent/verification/` — release-time artifacts
